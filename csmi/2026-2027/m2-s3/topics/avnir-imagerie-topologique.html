2. Project context

This project is central to Avnir Energy’s activity: providing the emerging nuclear industry with tools and methods for monitoring industrial structures, such as reactor vessels. It aims to implement topological imaging, a process similar to ultrasound imaging that detects small defects within a material, such as air bubbles in a weld.

The main steps are:

  1. High-fidelity modelling of ultrasonic wave propagation and reflections in a healthy medium, represented by an idealised numerical model.

  2. Simulation of the same medium with one or more defects. This initially replaces experimental measurements during prototyping; eventually, vibration measurements from the actual structure will be used.

  3. Modelling of the inverse problem: the time-reversed perturbation, computed as the healthy solution minus the defective solution, is injected into the healthy medium.

  4. Computation of a topological norm, a time integral at every point in the medium, whose non-zero values reveal defects.

The main challenges are:

  • Accurate calculations for high-fidelity wave representation.

  • Computational efficiency: ultrasonic frequencies are of the order of MHz and require very fine spatial and temporal discretisation. Computational cost must be controlled for industrial use.

  • Understanding wave propagation, time reversal and signal analysis.

3. Objectives

This M2 project follows an M1 internship and may serve as preliminary work for an M2 internship.

Several challenges remain:

  1. Implement the entire workflow with Feel++, ideally in a single program that automates the sequence of calculations.

  2. Develop a detailed understanding of the inverse problem and its mathematical adjoint formulation (step 3).

  3. Compute the topological norm accurately and efficiently (step 4).

  4. Use spectral finite elements for steps 1 and 2.

Given the limited duration of the M2 semester project, the initial focus will be on implementing the complete workflow.

4. Fields

Modelling, simulation, optimisation and control; high-performance computing; wave propagation physics.

5. Mathematical tools

Finite element methods; possibly spectral element methods.

6. Computing tools

Feel++, Python scripting, Git and ParaView.
