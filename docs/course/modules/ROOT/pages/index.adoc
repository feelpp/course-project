= Course Project — M1 and M2
:!numbered:

Reproducible computational science and professional scientific software practice are the common thread of this course in the Master CSMI.

[cols="1,1",options="header"]
|===
|M1 — Computational foundations |M2 — Scientific software and MLOps
|Work autonomously on a Linux-based scientific project, locally and remotely, using Git/GitHub and appropriate development tools.
|Engineer, package, automate, test and reproduce a computational or machine-learning application.
|xref:m1:index.adoc[Follow the M1 learning path] · xref:m1:project.adoc[M1 semester project]
|xref:m2:index.adoc[Follow the M2 learning path] · xref:m2:mlops/project.adoc[MLOps project]
|===

The practical target is to operate on Gaya using Slurm and Apptainer to deploy {feelpp}, then build a simulation-to-ML pipeline: prepare inputs → HPC simulations → dataset → training → inference → verification.
