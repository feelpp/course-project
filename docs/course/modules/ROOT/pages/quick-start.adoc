= Software and accounts

== Common workspace

Use a Linux shell locally or on an institution-provided machine. Windows users can use xref:vscode:wsl.adoc[WSL]; macOS users can develop locally and use a Linux host for Apptainer. You need Git, an OpenSSH client, VS Code and the Remote - SSH extension. Follow xref:vscode:install.adoc[VS Code setup] and xref:linux:ssh/ssh-setup.adoc[SSH setup].

[source,bash]
----
git --version
ssh -V
python3 --version
c++ --version
----

Set your Git author name/email, sign in to GitHub and accept the course organization/repository invitation. Keep a passphrase on your private SSH key; register only the public key. A GitHub account and a Gaya account are separate identities.

== Download and run the notebooks

Use *Download the Notebooks* in the header, extract the ZIP and open the extracted `course-project` folder in VS Code. In its terminal, run `uv sync --locked` to create `.venv` from the included `pyproject.toml` and `uv.lock`. Install the recommended Python/Jupyter extensions, open a notebook and choose `.venv` in *Select Kernel → Python Environments*.

The archive contains only the teaching notebooks, their required local resources (if any), and the VS Code/uv setup files. The current notebooks have no bundled input datasets. The short README covers Linux shell requirements and the separate native {feelpp} environment needed by its example. Course pages and project materials remain on the website.

== M1

. Verify the xref:m1:environments.adoc[Python and {cpp} environments].
. Check `ssh gaya` using the institution-issued login and host details.
. Open your remote working folder with xref:linux:ssh/remote-ssh-vscode.adoc[VS Code Remote SSH].
. Check xref:m1:gaya.adoc[Gaya access and scheduler instructions].

Do not install system packages or change services on a shared cluster. Use the supplied modules and user environments. Ask the teaching team about missing account access, required network/VPN access, or compiler modules.

== M2 — prepare Apptainer first

On the Linux machine allocated for the session, run:

[source,bash]
----
apptainer --version
----

Use xref:containers:apptainer/apptainer-install.adoc[the access/install guide] if it is missing. Pulling images needs registry access and enough disk quota; building may require facilities that are disabled on shared clusters. The first exercise can run from a prebuilt SIF supplied by the teaching team. Start with xref:containers:apptainer/tutorial.adoc[the practical tutorial].
