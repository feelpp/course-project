= Access to Apptainer

== Student route

Apptainer runs on Linux. Use the course Linux host, or a supported Linux VM/WSL environment on a personal computer. On Gaya, use the administrator-provided installation/module; confirm its name with the teaching team.

[source,bash]
----
command -v apptainer
apptainer --version
----

If these fail on a shared host, ask which environment/module to use. A laptop terminal or ordinary hosted development container is not automatically a suitable Apptainer build environment.

== Personal Linux installation

Choose packages and configuration for your distribution from the https://apptainer.org/docs/admin/latest/installation.html[official installation guide]. Install only on a machine you administer. Verify the version and complete the xref:apptainer/tutorial.adoc[pull/exec exercise] before attempting a definition-file build.

== When building is unavailable

Use an image prepared by the instructor on an approved build host. Check its SHA-256 against the supplied manifest. Execution of a SIF does not imply permission or support for every build mode. Registry/network access, quota and host architecture must also match the exercise.

The xref:apptainer/install-source-legacy.adoc[historical source-install recipe] is retained for reference; it is not required for this course.
