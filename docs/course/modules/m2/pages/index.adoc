= M2 — Scientific software and MLOps

== Why this matters

A model or simulation is useful to others when its environment, data, code and results can be identified and reproduced. M2 assumes M1 shell, Git, Python and remote-computing skills; xref:transition.adoc[review only the gaps you need].

== Learning outcomes

Deploy Feel++ with Apptainer and Slurm on Gaya; prepare parameterized simulations, assemble a verified dataset, train and track regression models, package inference and verify predictions against held-out Feel++ results. Test the stages and build a CI pipeline. Explain and defend the main engineering choices and scientific limitations.
