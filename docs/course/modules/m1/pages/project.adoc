= M1 semester project

== Objectives

Answer a scientific question while demonstrating autonomy in Linux, Python/{cpp}, remote computing and collaborative software practice. Agree the topic and scientific validation with the supervisor. Existing xref:csmi::2026/m1-s2/topics/index.adoc[2026 M1 S2 topics] remain available as that cohort's material; future assignments and deadlines are announced by the teaching team.

[#workflow]
== Expected workflow and GitHub organization

Maintain a repository with source, tests, small fixtures, environment instructions and a README. Use issues, branches, PRs, reviews, labels, milestones and a GitHub Project board. Record each member's contributions. Apply xref:workflow.adoc[testing/basic CI] to changes; use xref:gaya.adoc[Gaya] when remote execution is appropriate.

[#deliverables]
== Deliverables

* A report describing the problem, method, validation and limits.
* Source at an identified commit/tag, tests and CI evidence.
* Input provenance and instructions for environment setup and execution, including a scheduler script when needed.
* A clean-checkout reproduction record with commands and expected results.
* Issue/PR/review links, contribution statement and any permitted AI-use disclosure.

[#assessment]
== Assessment

Demonstrate scientific correctness, a reproducible workflow, code quality and collaboration. In an individual practical/oral check, explain your contribution, operate the shell/Git workflow, run Python, compile a small {cpp} program and interpret a job or test failure. See xref:ROOT:assessment.adoc[M1 competencies]. Dates and grading weights are supplied with the assignment.
