== Project context

Build a simplified digital model of resistive magnets in operation

== Objectives

Create a ODE base circuit model for LNCMI magnets in operation coupled with a model of the cooling system.

== Fields

Data and machine learning; modelling, simulation, optimisation and control.

== Mathematical tools

ODE and 1D Pde models; Parameters identifications; Eventually Data assimilations

== Computing tools

Python with SciPy, JAX and scikit-learn; an existing ODE module is available in a GitHub repository. C++ with SUNDIALS may be considered depending on performance. GitHub for code management.
