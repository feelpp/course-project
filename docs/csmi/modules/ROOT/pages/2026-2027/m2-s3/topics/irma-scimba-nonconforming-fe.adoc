== Project context

The project contributes to the development of Scimba, specifically its finite-element capabilities.

== Objectives

Implement a fully differentiable two-dimensional nonconforming finite-element solver.

== Fields

Modelling, simulation, optimisation and control.

== Mathematical tools

Nonconforming finite elements and automatic differentiation theory.

== Computing tools

Python, with JAX or PyTorch.
