== Project context

The project studies mosquito population suppression as a way to reduce arbovirus epidemic risk.
It focuses on the Incompatible Insect Technique (IIT): releasing male mosquitoes carrying a Wolbachia strain combination that is incompatible with local females, reducing the number of viable offspring.
This suppression approach is distinct from population replacement strategies.

The central question is how to distribute a fixed release budget in space and time: uniformly, in highly productive breeding areas, or adaptively as the population evolves.
A synthetic urban and peri-urban landscape inspired by Strasbourg provides a starting point; real data are welcome but are not required.

== Objectives and common core

* Build a reaction–diffusion model of mosquito life stages, larval competition, adult dispersal and cytoplasmic incompatibility.
* Check units, nondimensionalise the equations and analyse the spatially homogeneous model without intervention.
* Develop and verify a reproducible solver in one dimension, extending to two dimensions if feasible.
* Compare at least three release strategies with a no-intervention baseline, using the same total budget, time horizon and logistical constraints.
* Relate mosquito suppression to a vectorial-capacity indicator or, optionally, a coupled SEI–SEIR host–vector model.
* Assess the robustness of the conclusions against at least three uncertain biological or spatial parameters.

The common core represents approximately 80% of the proposed work.
The remaining scope can focus on one extension chosen with the supervisor.

== Release strategies to compare

* Uniform weekly releases.
* Two half-dose releases per week.
* Targeted releases in the most productive breeding areas.
* A large initial release followed by maintenance doses.
* Feedback-based releases using population observations, accounting for delays and measurement noise.
* A protective release barrier or a moving release front.

Compare cumulative female abundance, suppression, rebound after releases stop, spatial coverage and logistical effort.
If the epidemic module is included, also compare cumulative incidence.

== Research directions to choose from

The extension can be adapted to the student's interests and strengths:

* *Environmental modelling:* temperature and seasonality, rainfall-dependent breeding capacity and egg diapause.
* *Biological detail:* distinguish unmated, fertile and sterile females; investigate sorting errors and the risk of population replacement.
* *Spatial control:* boundary immigration, recolonisation, release barriers, anisotropic diffusion or weak advection.
* *Optimisation and observation:* optimal control, a discrete adjoint, robust optimisation or adaptive strategies using delayed, imperfect trap observations.
* *Epidemiology:* a full host–vector epidemic module with an imported human case.
* *Technique comparison:* IIT alone versus combined IIT and sterile-insect techniques (IIT–SIT), accounting for residual fertility.

== Mathematical and computing tools

Reaction–diffusion PDEs, dynamical systems, dimensional analysis, impulsive control, constrained optimisation and sensitivity analysis.
Finite-volume, finite-difference or finite-element methods may be used, with implicit diffusion and an IMEX treatment if stiffness requires it.
Grid searches, experimental designs or derivative-free optimisation are sufficient for the common core; an adjoint method is optional.

Suitable implementations include Python with NumPy/SciPy, Julia, FreeFEM or FEniCS.
Verification should cover reaction-only limits, reference diffusion solutions, mesh and time-step convergence, release-budget conservation, nonnegativity and mass balances.
All simulation figures must be reproducible from the supplied code and parameters.

== Expected deliverables

* A scientific report of 12–16 pages, excluding appendices.
* A documented code repository with parameters, synthetic data and automated verification tests.
* An oral presentation of approximately 12 minutes.
* A short discussion of model limitations, safety issues and the conditions required for a possible field study.

The proposed semester plan progresses from framing and model analysis to solver verification, strategy comparison, sensitivity analysis and final synthesis over 14 weeks.
