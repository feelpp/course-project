== Project context

The numerical simulation of nonlinear compressible hyperelastic solids is quite challenging due to the different physical processes that have to be combined. Furthermore the solution structure can be quite challenging due to the different wave types arising in the model (shear, fast and slow longitudinal waves etc). The capturing of discontinuities is quite important in particular for slow moving contact waves.

== Objectives

The project includes the understanding of the equations (optional different models), the numerical implementation in 1 or 2 dimensions and including mesh refinement to capture discontinuities with high resolution.

== Fields

Modelling, simulation, optimisation and control.

== Mathematical tools

Theory for systems of hyperbolic conservation laws, numerical methods (exact Riemann solvers vs finite volume approximation), mesh refinement techniques on Cartesian grids

== Computing tools

Python implementation, possible implementation in parallel
