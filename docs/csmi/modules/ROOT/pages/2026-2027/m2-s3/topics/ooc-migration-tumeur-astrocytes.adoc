== Project context

This project belongs to a CNR–Unistra collaboration within D3 4Health. It builds on two M1 projects on image registration and cell tracking in a brain organ-on-chip with glioblastoma cells and astrocytes. A new longer imaging campaign now allows migration data to be linked to a calibrated PDE model.

== Objectives

Build a reproducible pipeline from registered cell trajectories to migration observables, and use it to calibrate diffusion and taxis parameters of a reduced tumour–astrocyte PDE model, with quantified uncertainty.

== Fields

Data and machine learning; modelling, simulation, optimisation and control; signal and image processing.

== Mathematical tools

Kernel density estimation for micro-to-macro reconstruction; statistics of cell trajectories (MSD, persistence, non-parametric tests); reaction–diffusion–taxis PDEs solved with HDG/finite elements in Feel++ (CFPDE); inverse problems and parameter estimation (least squares, profile likelihood or Bayesian inference); sensitivity analysis, identifiability and uncertainty quantification; affine/projective transforms for image registration.

== Computing tools

Python scientific stack (NumPy, SciPy, pandas, scikit-image, OpenCV) for image processing, tracking and statistics; CZI readers for confocal data; Feel++ (CFPDE toolbox, Python interface) for PDE simulation on the chip mesh; Gmsh and ParaView for meshing and visualization; optimization/Bayesian libraries (SciPy, emcee or PyMC); Git/GitHub, Jupyter and CLI packaging for reproducibility.
