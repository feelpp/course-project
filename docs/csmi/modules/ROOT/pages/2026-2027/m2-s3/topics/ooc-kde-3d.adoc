== Project context

Part of the Project: D34Health (Digital Driven Diagnostics, prognostics, and therapeutics for sustainable Healthcare, for the development of digital twin of cancer-on-chip biological experiments

== Objectives

Develop a framework/pipeline used for the digital twin of Cancer-on-Chip experiments. The project intends to create numerical methods in order to use cell tracking data in microscopic and macroscopic mathematical models which then is used for calibration and validation of in-silico models against real experimental data.

== Fields

Data and machine learning; modelling, simulation, optimisation and control; high-performance computing; signal and image processing.

== Mathematical tools

Numerical Analysis, Simulation, Data Analysis, Inverse Problems, Calibration
